# 100LS 聽說功能實作計畫

_2026-10-13 · A-002 · 狀態：等待你看過並回答「待決定事項」，回答前不會動工_

## 摘要

- **目標：** 把網站從「用電影背單字」改成「陪你照 100LS 五步驟練一部片」，補上最缺的「聽」和「說」。

- **關鍵做法：** 讓你在網頁中直接播放「自己電腦裡的影片檔」。檔案只留在你的瀏覽器裡，不會上傳。網站依字幕時間點逐句播放、重播、放慢，再搭配錄音對照和「已說 N 遍」計數。

- **一併補足現況：** 修好版面跑掉、按鈕沒反應、統計頁假數字、填空頁拿錯電影題目這四個問題。

- **需要你決定：** 下方「待決定事項」共 6 題，每題都有建議答案。請直接在每題的 `- ans:` 後面填寫，寫「照建議」也可以。

## 1. 要達成的結果

- 你選一部電影後，會看到這部片的五步驟進度，清楚知道自己現在在第幾步、下一步要做什麼。

- 步驟 4（逐句練到跟上速度）和步驟 5（關字幕跟說 100 遍）有實際可用的工具，不再只是佔位按鈕。

- 進度會保存。關掉瀏覽器、隔天再打開，仍會停在原本的步驟和次數。

- 首頁、統計、填空頁顯示的都是真實內容，不是寫死的假資料或其他電影的題目。

## 2. 現況和計畫的對照

| 100LS 步驟 | 現在 | 做完這份計畫後 |
|---|---|---|
| 1. 無字幕看完整部片 | 沒有 | 用自己的影片檔在網頁中播放，不顯示字幕；看完按「完成這一步」 |
| 2. 開中文字幕再看 | 完整字幕只有英文 | 可另外載入自己的中文字幕檔（.srt）同步顯示；沒有中文字幕檔時，就在自己的播放器看完再打勾 |
| 3. 換英文字幕，查不懂的字 | 只能看系統事先挑好的生字 | 點英文字幕裡任何一個字，就能把它連同原句加入「我的生字本」 |
| 4. 逐句練到跟上速度 | 沒有 | 逐句播放原聲、單句重播、0.75 倍慢速、錄下自己的聲音對照，每句可標記「跟上了」 |
| 5. 關字幕跟說 100 遍 | 按鈕沒反應 | 關掉字幕播放、跟著說，每說完一輪就 +1，顯示「第 N / 100 遍」 |

## 3. 做法

### 3.1 不需要新增資料庫表格

- 網站目前沒有登入功能，等於只有你一個使用者。

- 學習進度、每句次數、我的生字本，都存在瀏覽器內建的小型儲存空間（localStorage）。

- 好處是不必改資料庫結構，也不會新增任何「從瀏覽器寫入資料庫」的管道。

- 限制是換電腦或換瀏覽器時，進度不會跟著過去。解決方式列在待決定事項 Q5。

### 3.2 影片和聲音

- 影片檔由你自己選取（例如 `Inception.mp4`）。瀏覽器只是在本機播放它，網站伺服器完全收不到這個檔案，所以不會有散布影片的版權問題。

- 字幕時間點來自資料庫既有的英文字幕（`subtitles.srt_content` 欄位）。

- 字幕和影片的時間可能差個一兩秒，所以會提供「字幕提早／延後 0.5 秒」的微調按鈕。

- 沒有影片檔時，可改用瀏覽器內建的電腦朗讀當備用。它不是演員原聲，只適合練發音。

### 3.3 錄音對照

- 使用瀏覽器內建的錄音功能。第一次使用時，瀏覽器會詢問是否允許使用麥克風。

- 錄音只保留在目前的頁面中，播放比較後就丟棄，不存檔也不上傳。

### 3.4 新增的頁面和檔案

- 新頁面 `/learn/<影片ID>`：五步驟學習頁，上方顯示五步驟進度條，下方顯示目前這一步的工具。

- `src/utils/srt.js`：把字幕文字拆成「第幾句、開始時間、結束時間、台詞」的清單。首頁目前也有一段類似的程式，計畫會讓兩邊共用這一份。

- `src/utils/progress-store.js`：讀取和保存學習進度。

- `src/components/learn/`：影片播放器、逐句清單、錄音按鈕、次數計數器等元件。

### 3.5 補足現有的問題

- **版面跑掉：** 程式用了 Tailwind（一套用樣式名稱排版的工具），但專案沒有安裝。計畫會安裝它，讓既有頁面和新頁面都正常顯示。

- **6 個學習模式按鈕沒反應：** 改成真的會帶你到對應的頁面。「觀看字幕」和「跟讀練習」改為進入新的五步驟學習頁。

- **統計頁假數字：** 改成顯示真實資料：已開始的影片數、每部片目前在第幾步、累計跟說次數、我的生字數。沒有資料的項目就顯示「尚無資料」。

- **填空頁拿錯電影的題目：** 選到沒有題目的電影時，改成顯示「這部片還沒有題目」，不再改用《教父》的範例題。

### 3.6 實作順序

每個階段完成後都可以單獨使用，也會各自提交一次（commit，Git 的存檔點）。

1. **階段 0：安全修正**（是否排在最前面，看 Q1 的回答）

   - 把「任何人都能送 SQL 給資料庫執行」的 `/api/query`，改成只提供幾個固定查詢，例如「取得影片清單」「取得某部片的字幕」。瀏覽器只能傳影片 ID 這類參數。

2. **階段 1：基礎**

   - 安裝 Tailwind、建立測試工具（見下方「測試方式」）、字幕拆句、進度保存。

3. **階段 2：五步驟學習頁**

   - 進度條、每一步的說明和「完成這一步」按鈕、本機影片播放器、步驟 1 和步驟 2。

4. **階段 3：聽和說的工具**

   - 步驟 4 的逐句播放、重播、慢速、錄音對照、「跟上了」標記。

   - 步驟 5 的關字幕播放和 100 遍計數。

5. **階段 4：步驟 3 生字本和現有問題**

   - 點字加入我的生字本，修好首頁按鈕、統計頁、填空頁。

### 3.7 測試方式

- 專案目前沒有單元測試工具（單元測試是用程式自動檢查一小段功能）。計畫會加裝 Vitest，只拿來測試字幕拆句、進度保存、步驟解鎖這些邏輯。

- 畫面操作沿用專案已經安裝的 Playwright（會自動開瀏覽器點按的測試工具），在本機開發站跑完整流程。

- 測試用的影片會用幾秒鐘的自製測試片，不會使用真實電影。

## 4. 最小範圍檢查（Minimality check）

- **最小可用版本：** 只做步驟 4 和步驟 5 的逐句工具，因為這兩步是 100LS 的核心，也是網站完全沒有的部分。

- **考慮過的更簡單做法：** 只做計數器，不播放影片（你在 Netflix 播，網站只負責記次數）。

  - 沒有選它的原因：這樣網站無法「單句重播」和「放慢」，步驟 4 等於還是要你自己在播放器上拉時間軸，練習體驗跟現在差不多。

- **每一部分為什麼需要：**

  - 本機影片播放：沒有它，就做不到逐句聽原聲。

  - 進度保存：100LS 要練很多天，沒有保存就無法累積到 100 遍。

  - 五步驟進度條：書的方法是照順序做，需要讓你知道現在在哪一步。

  - Tailwind 和四個現況問題：你要求「把現在的開發進度補足」，而且新頁面也需要 Tailwind 才能正常顯示。

  - Vitest：拆句和進度保存出錯會讓次數算錯，需要自動測試把關。

- **刻意不做的事：** 登入和帳號、雲端同步、自動翻譯、發音評分、上傳影片到伺服器。之後如有需要，再另外規劃。

## Invariants

- **INV-1 影片和錄音不離開你的電腦**

  - 起始狀態：你選了本機影片檔，或錄了一段聲音。

  - 必須保持：網站不會把影片或錄音傳送到任何伺服器。

  - 違反的情況：瀏覽器的網路紀錄中出現影片或錄音的上傳請求。

- **INV-2 進度保存後不會遺失或算錯**

  - 起始狀態：某部片在步驟 4，第 12 句已說 7 遍。

  - 必須保持：重新整理頁面或隔天再打開，仍然是步驟 4、第 12 句 7 遍；不同電影的進度互不影響。

  - 違反的情況：次數歸零、跳號，或 A 片的次數出現在 B 片。

- **INV-3 既有功能照常運作**

  - 起始狀態：目前的字幕顯示、重要對話、生字筆記、生字測驗、填空練習都能使用。

  - 必須保持：這些功能的內容和操作方式不變；只修正第 3.5 節列出的四個問題。

  - 違反的情況：既有頁面出錯、資料不見，或操作方式在沒有說明的情況下改變。

- **INV-4 不改資料庫結構，不新增寫入管道**

  - 起始狀態：資料庫有 movies、subtitles 等現有表格。

  - 必須保持：不新增或修改任何表格，也不新增任何從瀏覽器寫入資料庫的功能。

  - 違反的情況：出現 CREATE / ALTER 等改結構的指令，或新增的程式會對資料庫寫入資料。

## Acceptance criteria

驗收時每一項都會實際操作或執行測試。「通過」和「不通過」的範例如下：

- **AC-1 五步驟進度和保存**（INV-2）

  - 通過：在 Inception 把步驟 1、2 標為完成，重新整理後進度條顯示步驟 1、2 已完成，目前在步驟 3；切換到另一部片時，進度是全新的。

  - 不通過：重新整理後進度消失，或兩部片的進度混在一起。

  - 檢查方式：Vitest 測試進度保存邏輯，再用 Playwright 實際重新整理頁面確認。

- **AC-2 逐句播放原聲**（INV-1）

  - 通過：載入本機測試影片後點第 3 句，影片從第 3 句開始播放，播到第 3 句結束就停；按「重播」會重播同一句；切換到 0.75 倍時，播放速度變慢。

  - 不通過：播放超過句尾、跳到別句，或網路紀錄中出現影片上傳。

  - 檢查方式：Playwright 用測試影片檢查播放位置和速度，並檢查網路請求。

- **AC-3 錄音對照**（INV-1）

  - 通過：按「錄音」後說話，按「停止」，可以先播放原句、再播放自己的錄音。

  - 不通過：沒有聲音、無法播放錄音，或錄音被上傳。

  - 檢查方式：Playwright 使用模擬麥克風跑一次，再由你用真實麥克風試一次。

- **AC-4 跟說次數**（INV-2）

  - 通過：第 12 句按 3 次「+1」，顯示「3 / 100」；整部片完成一輪，顯示「第 1 / 100 遍」；重新整理後數字不變。

  - 不通過：次數沒有增加、重複計算，或重新整理後歸零。

  - 檢查方式：Vitest 測試計數邏輯，再用 Playwright 重新整理確認。

- **AC-5 步驟 3 點字加入生字本**（INV-2、INV-4）

  - 通過：在英文字幕點 "subconscious"，我的生字本出現這個字和它的原句；重新整理後仍然在。

  - 不通過：點了沒有反應、原句錯誤，或程式嘗試寫入資料庫。

  - 檢查方式：Playwright 實際點選並檢查網路請求。

- **AC-6 現況問題修好**（INV-3）

  - 通過：測驗、統計、填空頁的按鈕有顏色，內容不再只擠在左半邊；首頁 6 個按鈕都會換頁；統計頁沒有資料時顯示「尚無資料」；選 Inception 進填空頁時顯示「這部片還沒有題目」。

  - 不通過：任何一項仍是舊的行為。

  - 檢查方式：Playwright 截圖，和 A-001 的截圖比對。

- **AC-7 安全修正**（只有 Q1 回答「要」才做）

  - 通過：直接送一段任意 SQL 給網站後端時被拒絕；網站各頁面照常載入影片和字幕。

  - 不通過：任意 SQL 仍會被執行，或頁面因此載入失敗。

  - 檢查方式：自動測試確認後端拒絕任意 SQL，再用 Playwright 逐頁檢查。過程只做唯讀驗證，不對正式資料庫寫入。

- **AC-8 既有功能不受影響**（INV-3、INV-4）

  - 通過：字幕、重要對話、生字筆記、生字測驗的內容和 A-001 的截圖相同；程式中沒有新增改資料庫結構的指令。

  - 不通過：既有頁面出錯，或內容不見。

  - 檢查方式：`npm run build` 成功，再用 Playwright 逐頁比對，並搜尋程式碼確認沒有新增 CREATE、ALTER 指令。
