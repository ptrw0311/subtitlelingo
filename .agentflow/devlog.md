## [FINAL REPORT]

1. 「請幫我分析這個網站開發的功能，以及能不能符合我要學習英文的理念」

   - **目前已有的功能**

     - 選電影：首頁有「最近練習」卡片和下拉選單，資料庫目前有 7 部影片。

     - 看字幕：顯示整部片的英文字幕原文（SRT 檔，也就是附時間碼的字幕文字檔）。

     - 重要對話：挑出的精選台詞，點一下可看中文翻譯和時間點。

     - 生字筆記：每個單字有詞性、中文解釋、電影原句、3 個例句，可依程度篩選。

     - 測驗：生字選擇題（`/quiz`）和台詞填空題（`/practice/<影片ID>`）。

     - 複習與統計：程式裡已有「間隔複習」（Leitner 卡片盒，答對就隔久一點再考）的計算邏輯，以及學習統計頁。

   - **對照 100LS 五個步驟**

     | 步驟 | 網站現況 | 符合程度 |
     |---|---|---|
     | 1. 無字幕看完整部片 | 沒有影片或聲音播放 | 沒有 |
     | 2. 開中文字幕再看 | 只有「重要對話」有中文；完整字幕只有英文 | 部分 |
     | 3. 換英文字幕，查不懂的單字 | 英文字幕 + 生字筆記 + 測驗 | 最符合，但單字是系統事先挑好的，不能自己點字幕裡不懂的字加入 |
     | 4. 反覆練每句台詞到跟上速度 | 沒有逐句播放、重播、放慢速度 | 沒有 |
     | 5. 關字幕跟著說 100 遍 | 「跟讀練習」按鈕只是佔位，沒有錄音，也沒有次數計數 | 沒有 |

   - **結論：方向和理念有落差**

     - 書的重點是「不靠背單字、文法，靠反覆聽和跟讀」；網站目前的主力剛好是單字和選擇題，也就是書說不要依賴的部分。

     - 100LS 強調「一部片練到底、練 100 遍」；網站的設計是鼓勵換很多部片、看學了幾部片，方向相反。

     - 最大的技術限制是聲音來源：網站不能放整部電影（有版權問題）。比較可行的做法是讓網站當「陪練工具」，電影由你自己在 Netflix、DVD 等地方播放。

   - **建議補上的功能（依重要性排序，尚未實作）**

     1. 五步驟進度表：每部片顯示目前在第幾步，打勾完成才進下一步。

     2. 逐句跟讀計數器：依字幕時間碼列出每一句，每句一個「已說 N / 100 遍」的計數，可以先關掉英文只看時間點。

     3. 錄音對照：用瀏覽器內建錄音錄下自己的跟讀，再重播比較。

     4. 逐句聽：可以先用瀏覽器內建的語音朗讀（電腦語音，不是演員原聲）；如果要用原聲，需要你自己上傳片段。

     5. 步驟 3 改成點字幕裡的字就能查詢並加入生字本，取代系統事先挑字。

   - **預覽時會看到的問題**

     - 測驗、統計、填空頁的版面跑掉（例如按鈕沒有顏色、內容只佔左半邊）。原因是程式用了 Tailwind 樣式名稱，但專案沒有安裝 Tailwind。

   - **安全風險（建議優先處理）**

     - 修正方向：改成後端只提供固定的幾個查詢，前端只能傳參數。
